SIMULADOR PRONABEC - RAZONAMIENTO VERBAL

1. Abra index.html con Chrome, Edge o Firefox.
2. La app incluye la base completa de preguntas y funciona sin Internet.
3. El JSON fuente está en data/questions.json.
4. Puede cargar otro JSON compatible desde el botón "Cargar otro JSON".
5. Los ejercicios visuales incluyen capturas de sus páginas originales en assets/pages/.
