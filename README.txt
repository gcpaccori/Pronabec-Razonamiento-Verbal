SIMULADOR PRONABEC · RAZONAMIENTO VERBAL
VERSIÓN MOBILE-FIRST 2.0

CÓMO ABRIR
1. Abra index.html con Chrome, Edge o Firefox.
2. No requiere instalación ni Internet.
3. La base completa de 280 preguntas está incluida.

MEJORAS DE INTERFAZ
- Diseño mobile-first para teléfonos.
- Navegación inferior fija: Anterior / Marcar / Siguiente.
- Menú lateral deslizable para temas, búsqueda, resultados y configuración.
- Mapa de preguntas en panel táctil.
- Alternativas grandes y cómodas para responder con el pulgar.
- Progreso compacto y persistente.
- Modo Práctica con retroalimentación inmediata.
- Modo Examen sin mostrar respuestas antes de finalizar.
- Resultados adaptados a pantalla móvil.
- Soporte para safe areas de iPhone y pantallas pequeñas.
- Conserva importación de JSON, material visual, zoom, búsqueda y exportación.

DATOS
- JSON fuente: data/questions.json
- Imágenes originales: assets/pages/

NOTA
La aplicación sigue siendo estática y portable: puede copiar esta carpeta completa
a una PC o celular y abrir index.html sin servidor.
